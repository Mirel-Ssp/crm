批次5 交付 v0.5 后端测试 38/38 通过 端到端冲烟 83/83 通过 性能抽测 漏斗5000条 P95=40.8ms · STAT P95=20.4ms 前端构建通过 主包 10.9KB + echarts 分包

基于 Spring Boot 3 + Vue 3 的模块化单体 CRM。v0.1 交付登录认证（JWT 双令牌）→ 客户管理 → 工作台 KPI；批次2 新增权限底座 → 系统管理 → 线索闭环；批次3 新增商机管理 → 待办看板 → 报表中心 → 客户增强 → 自助改密；批次4 新增交易板块 P0 全量收口（标的/订单六态状态机/汇款核销/动态通知/交易工作台）；本期（批次5）新增：客户服务工单（四态状态机 + 指派/处理/回访满意度）→ 客户价值评分（五维加权 + 每日重算 + 分层唤醒）→ 多维统计（年季月日聚合预计算 + 同环比 + 排名/标的分析 + 明细 CSV）→ WebSocket 实时推送（轮询兜底保留）→ 交易全链路集成测试 + 5000 条压测口径。

9. 接口约定

  • 统一响应：{"code":0,"message":"success","data":...}；业务错误为 HTTP 200 + code≠0（如 40000 参数/重名、40100 未登录、40300 越权、40400 不存在、30001 核销超限、40900 数据冲突）。
  • 认证：请求头 Authorization: Bearer <accessToken>；令牌过期用 POST /api/auth/refresh 换新。
  • 主要接口：/api/customers（+contacts/check-duplicate/merge/timeline/business）、/api/followups（+todo/done/reschedule）、/api/workbench/summary|trade、/api/leads（+claim|assign|convert|invalidate）、/api/opps（+stage|win|lose、/funnel、/loss-stats）、/api/reports/customer|lead|opportunity（+/export）、/api/trade/items（+on|off|price、/rules）、/api/trade/orders（+approve|reject|cancel）、/api/trade/remit（+confirm|reject|write-off）、/api/notify/feed|unread|read、/api/tickets（批次5：+{id}/assign|process|resolve|visit|close、/satisfaction/summary）、/api/value（批次5：/scores、/distribution、/scores/{id}/trend、/silent（+/{id}/assign）、/recalc、/manual、/weights）、/api/stat（批次5：/summary、/rank、/items、/detail（+/export）、/rebuild）、/api/auth/password、/api/system/orgs|users|roles、/api/dicts。
  • 实时推送：ws://localhost:8080/ws/notify?token=<accessToken>（通知事件秒级推送；前端 WS 断开自动回退 5s 轮询）。
  • 接口文档（Swagger）：http://localhost:8080/swagger-ui.html

10. 常见问题

Q：mvn 不是内部命令？
Maven 未加入 PATH 时直接使用完整路径：& 'C:\Users\21925\.local\share\apache-maven-3.9.16\bin\mvn.cmd' test
Q：pnpm install 报 esbuild 校验错误？
使用 pnpm install --ignore-scripts（esbuild 二进制走 optionalDependencies 自动就位）。
Q：后端起不来提示数据库连接失败？
先执行 dev-env\pg.ps1 start，并用 /api/health 确认 db:UP。
Q：Windows PowerShell 运行中文脚本乱码/报语法错误？
PS 5.1 对无 BOM 的 UTF-8 脚本按 GBK 解析，脚本内请保持纯 ASCII 输出（本仓库脚本已遵循）。
Q：PS 5.1 测 WebSocket 握手失败？
PS 5.1 ClientWebSocket 拒绝 vite ws-proxy 的 Connection: upgrade, keep-alive 101 响应（RFC 合法、浏览器正常）；请用 Node 22 内置 WebSocket 客户端验证（backend/scripts/ws-t3-node.mjs）。

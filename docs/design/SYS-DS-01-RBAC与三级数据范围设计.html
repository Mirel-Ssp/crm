RBAC 权限与三级数据范围设计

定义角色—权限点—数据范围三层模型。功能权限（能不能调这个接口）与数据权限（能看哪些行）分离；越权访问全部拦截并写入审计。

任务编号SYS-DS-01（对应需求 CRM-M1/M2，§5 安全）版本v1.0
编制日期2026-09-03落库sys_org / sys_user / sys_role / sys_permission / sys_user_role / sys_role_permission / sys_audit_log（V1 已建）

一、三层模型

用户 sys_user ──< sys_user_role >── 角色 sys_role ──< sys_role_permission >── 权限点 sys_permission
                                        │
                                        └─ data_scope: SELF / TEAM / ALL（数据范围挂在角色上）
  • 权限点三型：MENU（前端路由可见性）、BUTTON（页面操作可见性）、API（后端接口鉴权）。code 约定 模块:动作，如 order:confirm、remit:writeoff。
  • 角色预设：ADMIN（ALL）/ MANAGER（TEAM）/ SALES（SELF）；支持新增角色组合权限点与范围，不改代码。
  • 登录响应与 /api/auth/me 需附带 permissions[] 与 dataScope（SYS-DV-02 实现，本设计先行定形）。

二、功能权限（接口鉴权）

  • 后端注解式：@PreAuthorize("@ss.hasPerm('order:confirm')")；@ss 为注册的 PermissionService Bean，从当前用户权限集合判定（权限集合在 JWT 过滤器中随认证装载，用户态缓存走 CacheService，权限变更时 evict）。
  • 前端指令式：v-permission="'customer:create'" 无权限则隐藏/禁用按钮；前端隐藏只是体验，后端校验才是边界。
  • 越权（403）由 Security AccessDeniedHandler 输出 Result JSON，并在 SYS-DV-04 中挂 sys_audit_log 记录。

三、数据权限（行级过滤）

范围语义过滤实现
SELF仅本人数据owner_id = :uid（业务员默认）
TEAM本组织（含下级）数据owner_id IN (SELECT id FROM sys_user WHERE org_id IN :orgSubtree)（经理）
ALL全部数据不加过滤（管理员/财务）

3.1 实现机制：DataScopeInterceptor

  • MyBatis-Plus InnerInterceptor（或 Service 层统一 ScopeWrapper 工厂）对标注 @DataScope(ownerField="owner_id") 的 Mapper 查询自动注入 WHERE 条件，业务 Mapper 零侵入。
  • org 子树计算：登录时解析 sys_org 父子链（路径枚举表或递归 CTE）得到 orgSubtree，随用户态缓存。
  • 适用表：crm_customer / crm_lead / crm_opportunity / crm_followup / trade_order / trade_remittance / service_ticket（均有 owner_id）。
  • 例外：字典、通知（user_id 直查）不走范围过滤。

3.2 敏感操作的角色约束（需求映射）

操作约束
订单确认/撤销（OD-1）业务员可撤本人单；确认动作限 MANAGER/ADMIN（权限点 order:confirm）
汇款到账确认（RM-2）财务/管理员专属（remit:confirm），业务员只能登记
核销（RM-3）财务执行；全部校验服务端计算，防超核/防重复
客户移交（CUS-5）MANAGER 范围内移交；ADMIN 任意
系统管理（CRM-M）仅 ADMIN（system:manage）

四、用户态缓存与失效

  • 缓存内容：user:{uid} → { roles, permissions, dataScope, orgSubtree }，TTL 30 分钟（CacheService）。
  • 失效时机：角色/权限点变更、组织调整、用户禁用 → evict 对应 user 缓存；下次请求重载。
  • JWT 本身在有效期内无法提前作废（无状态）；禁用账号的即时生效通过每次请求重查用户态缓存的 status 保证——过滤器发现 DISABLED 即 401。
